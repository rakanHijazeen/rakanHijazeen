### 💻 Key Projects

#### 🏋️‍♂️ [Vertex Fit](https://github.com/rakanHijazeen/Vertex_Fit)
An AI-powered fitness coaching platform that combines real-time computer vision, multimodal LLMs, and bi-directional WebSockets for live biomechanical feedback.
- Engineered a real-time **live coaching pipeline** streaming webcam frames via **Django Channels** and **Redis** to Gemini Live for zero-latency audio/visual feedback.
- Integrated **MediaPipe Pose Estimation** to track 33 body landmarks, calculate joint angles, and power exercise-aware dynamic rep counting.
- Built a context-aware **Conversational AI Engine** that dynamically ingests user biometrics and historical workout logs into system instructions.
- Implemented **Paddle v2 Billing**, Webhook sync mechanisms, AWS S3 media storage, and a dual-mode video processing pipeline (Live Coach vs. Retroactive Uploads).

#### 🩺 [Medical AI Suite](https://github.com/rakanHijazeen/Medical-AI-Suite)
An end-to-end diagnostic decision support prototype that combines traditional machine learning classifiers with an advanced, multi-service **Conversational RAG pipeline**.
- Engineered a stateful **Conversational RAG system** allowing users to interactively query medical data while maintaining dialogue context and chat history.
- Containerized using **Docker** for seamless local pipeline replication.
- Implemented vector embeddings via **`pgvector`** for semantic data retrieval.
- Engineered a pipeline to parse data and auto-generate comprehensive evaluation reports.
